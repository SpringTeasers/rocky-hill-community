About this website

This is a community information site for Rocky Hill, Connecticut, built as a static website and published on GitHub Pages.

It is not an official town website and it does not accept, route or process town enquiries. For anything official — permits, payments, records, meetings, public safety — please use the Town of Rocky Hill’s own website and phone number above.
